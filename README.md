# Hairspring — support & privacy

The public pages App Store Connect requires for
[Hairspring](https://apps.apple.com/app/hairspring-timegrapher), a
timegrapher for mechanical watches.

- **Support:** https://kapella-hub.github.io/appstore/
- **Privacy Policy:** https://kapella-hub.github.io/appstore/privacy.html

Served by GitHub Pages from the `main` branch, root folder. `.nojekyll`
keeps Pages from running the files through Jekyll.

The support page is also the troubleshooting surface: placement, winding,
why amplitude is reported as a range, why a rate is sometimes withheld,
and how to send a diagnostic log.
